PRIVACY

Privacy policy

Draft — not ready for audit submission. The retention/deletion procedure and in-client privacy acceptance must be resolved before audit submission.

Draft prepared: 7 October 2026. This policy describes Hidden Works Analytics Local, a private Windows desktop client operated by the Hidden Works channel owner.

YouTube API Services

The client uses YouTube Data API v3, YouTube Analytics API and YouTube Reporting API. Google's handling of data is described in the Google Privacy Policy. Use of the client is also subject to the YouTube Terms of Service.

Information accessed and stored

With the owner's authorization, the client accesses channel identifiers, uploads playlist information, video identifiers, titles, publication dates, durations and visibility, and available non-monetary channel/video reports. Reports may contain views, watch time, audience retention, engagement, subscriber changes, aggregate geography, devices, demographics, traffic sources, search terms, thumbnail impressions and click-through rates where provided by Google. Video listings may include non-public video metadata; the default channel review covers currently public videos.

The client stores OAuth access/refresh credentials and downloaded reports. It does not request Google passwords or collect sign-in credentials. Sign-in occurs on Google's pages. It requests only https://www.googleapis.com/auth/youtube.readonly and https://www.googleapis.com/auth/yt-analytics.readonly.

Purpose and sharing

Data is used to review the performance of the owner's configured channel and inform documentary production. API requests and authorization communicate with Google over HTTPS. Reports are stored locally, not published by this website or included in the project's tracked repository. The owner may provide selected information to expressly authorized assistants for that editorial review; handling by those services is governed by their own privacy terms. The client contains no advertising or data-selling functionality.

Storage and security

OAuth credentials are stored outside the repository in a Windows DPAPI-encrypted vault restricted to the current Windows user. Downloaded reports are stored in the project's private .local/analytics/ directory, excluded from version control. These reports are not encrypted by the client; their protection depends on the owner's computer security and access controls.

Retention and deletion — current behavior

The current client has no automatic report-expiry or report-deletion mechanism. Existing reports remain until the owner removes them. Disconnecting removes the local credential vault and attempts to revoke the Google grant, but does not delete downloaded reports.

To delete downloaded data, the owner must remove the contents of .local/analytics/ and any copies of those reports or screenshots they have made. Local deletion does not delete videos, statistics or other data held by YouTube. A finite retention procedure, regular authorization checks, and deletion following revocation must be established before this draft can represent a submission-ready policy.

Revoking authorization

The owner can run analiticas.cmd disconnect to request revocation and remove locally stored credentials. If revocation fails, the client reports that manual revocation is required. Authorization can also be revoked at any time through Google's security permissions page or Google Account connections. Revocation and local report deletion are separate steps in the current version.

This information website

These pages have no sign-in form, analytics scripts, advertising, embedded player, external fonts or application cookies. If hosted on GitHub Pages, GitHub processes website requests under the GitHub Privacy Statement. Following links to Google or YouTube opens those services, which apply their own policies.

Contact

For privacy questions, complaints or requests to delete locally stored application data, contact the Hidden Works channel operator at aniol.youtube@gmail.com.

Changes

Changes to this policy will be reflected on this page with an updated date. This draft does not claim Google approval or verified API compliance.
