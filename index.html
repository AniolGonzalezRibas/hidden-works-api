PRIVATE DESKTOP CLIENT · APPLICATION INFORMATION

Hidden Works
Analytics Local

A local tool for understanding the performance of the Hidden Works documentary channel on YouTube.

This website describes the application and its privacy practices. The application itself runs on the channel owner's Windows computer and is not publicly distributed. There is no web login or public analytics dashboard.

What the application does

The client uses YouTube API Services: YouTube Data API v3, YouTube Analytics API and YouTube Reporting API. It retrieves the configured owner's channel and video information, and available non-monetary performance reports, to support editorial review.

It requests the youtube.readonly and yt-analytics.readonly OAuth scopes. It does not upload videos, edit channel content, or request revenue access. At the owner's explicit request, it can ask YouTube Reporting API to generate a non-monetary reach report.

Access and authorization

The owner launches the desktop application and authorizes it through Google's sign-in and consent screen. The client verifies that the authorized channel matches the configured Hidden Works channel.

For a compliance review, the operator must arrange access instructions and evidence through the audit submission. This page does not grant access to the desktop application.

Privacy and control

Read the privacy policy for data access, local storage, deletion and Google access revocation. The terms of use explain the client's permitted use.
